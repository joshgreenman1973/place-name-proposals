Board on Geographic Names quarterly review lists February 2023 to July 2026

Under review

Of 493 place-name proposals listed for federal review since February 2023, 147 would replace an existing name, 51 of them a name considered offensive or derogatory.

The Board decides the official name of every American stream, summit, lake and ridge, and anyone can file a proposal. Each becomes a case file stating who asked, the name they want, where the feature is and the reason they gave. Review lists 450 to 464 hold 493 proposals from 47 states and territories: 285 would name a feature that has no official name, 147 would change an existing name and 61 would make a local name official. A listing is not a decision, and this site does not track what the Board decided.
